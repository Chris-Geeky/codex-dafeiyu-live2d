# 1.0.0 发布验收清单

建议先发候选版。首个稳定版只承诺在已实测的 **Windows 11 x64 + Codex Windows 商店版** 组合上可用；在发布说明中列出具体系统与 Codex 版本。仍按非官方适配器分发。

## 候选版必须通过

| 项目 | 验收标准 |
| --- | --- |
| 干净环境首次安装 | 用普通账户从 GitHub 下载候选 ZIP，在至少一台非开发机或干净虚拟机完整解压。测试有空格和中文的路径、首次同意及下载 Core、取消同意、断网后重试。首次许可窗口在中英文 Windows 上应可直接读懂；当前全新安装默认中文，英文用户要先取消再切语言。记录 Windows、Codex 和 WebView2 版本。 |
| 启动、重连、恢复 | 测试 Codex 未启动、普通启动且已有工作、带通道启动、退出后重开，以及 Codex 更新后的重新检测。确认助手不代替用户关闭 Codex。测试恢复原图、原图暂不可用、强制结束助手后的恢复，以及卸载后从官方入口启动。 |
| 显示与输入 | 测试中英文、深浅主题、键盘操作，以及 100%、125%、150%、200% 缩放下的面板和图标。实际拖动、缩放主窗口；记录已知闪烁及绕法。要承诺混合 DPI 双屏支持，先补对应实机测试。 |
| 预览与设置 | 测试正常 WebView2 和缺失或初始化失败时的基础设置；验证退出再打开后语言、宠物大小和装扮仍正确，且切换主题、帧率和恢复原宠物可独立使用。 |
| 本机连接边界 | 在支持的 Codex 版本上核对监听仅在回环地址，连接和恢复前核对监听进程确属预期 Codex；目标身份、页面接口或进程状态对不上时，应停止接入并保留原宠物。界面和 README 应明确说明 CDP 无认证、退出助手不会关闭 Codex 的监听端口。 |
| 发布与回滚 | CI 从候选提交打包并验证同一个要发的 ZIP，检查 SHA-256、许可文件、中英文说明和启动器签名。测试从 0.5.13 升级并回退，确认偏好保留；提供对应的上一版下载入口。 |
| 安全软件与许可 | 使用默认安全防护测试实际从 GitHub 下载的包。计划用同一发布者身份签名并加时间戳；若收到具体检测，记录厂商、文件和检测名，走厂商复核，不要求用户放行。复核 Live2D SDK 发行条款以及模型、衍生头像的署名与非商业条件。 |

## 可以后补

只复制必要版本和状态的诊断摘要、手动检查更新，以及 Windows ARM64 或其他平台支持。应用内自动更新、安装器和更多装扮不影响首个稳定版的核心验收。
