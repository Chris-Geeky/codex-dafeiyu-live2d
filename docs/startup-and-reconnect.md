# 启动与自动重连

日常从 `CodexDafeiyu.exe` 或它的快捷方式打开即可：助手会一起打开 Codex 并接入大肥鱼。助手收起到托盘后继续监测；退出助手或选择恢复原宠物会停止监测。

如果想先用 Codex、需要时才开大肥鱼，可以创建一个指向 `"解压目录\CodexDafeiyu.exe" --codex-only` 的 Windows 快捷方式。助手和 Codex 都未运行时，从这个入口只打开 Codex，并为稍后接入预留本机通道。想用宠物时再正常启动助手，或在已暂停的助手中点“启用大肥鱼”。如果已经从官方图标启动了 Codex，新入口也不会重启它或改变它的接入状态。

## 为什么手动打开 Codex 后，仍会要求完整退出一次？

当前适配器需要 Codex 在启动时开启本机接入通道。从官方普通图标打开的进程通常未开启通道，运行中不能补上。助手可以识别这个新进程，但无法直接接入。

如果你先完整退出，又立刻自己点官方 Codex 图标，新进程通常仍没有通道，所以会再次遇到这一步。**看到“等待你完整退出 Codex”时，在系统托盘右键 Codex 图标 → 退出，之后由助手自动打开即可。** 只关主窗口可能仍在后台运行。原生宠物仍可正常显示，但 Live2D 不能接入，反复检测不会为这个进程补开通道。

v0.5.4 将原来的“等待接续打开 Codex”改为“等待你完整退出 Codex”，操作步骤直接写在状态卡片里；已安排接续时，按钮显示“等待 Codex 退出”，未安排时显示“需要重开 Codex 才能接入”。面板与托盘菜单保持一致，可用“停止自动接入”取消等候。助手不会代替你退出正在工作的 Codex。

## v0.5.3 的处理

| 发生的情况 | 助手如何处理 |
| --- | --- |
| 已有可连接的 Codex | 直接连接，优先选择具有接入通道的进程。 |
| Codex 退出后，用带通道的入口重新打开 | 识别新进程并重新接入。 |
| Codex 退出，暂时不再使用 | 显示“等待你打开 Codex”，保持监测，Codex 保持关闭。 |
| 点“打开 Codex”或再次运行助手入口 | 重新检测；没有进程时由助手打开 Codex。 |
| 手动从普通官方图标打开，没有接入通道 | 明确显示原因。点“安排接入”，再完整退出一次，由助手接续打开。 |
| 等候期间手动关掉又重开 | 重新识别最新进程，更新等待原因；不会只盯着旧进程。 |
| 助手已在后台，又双击一次助手 | 复用现有助手；连接中只显示面板，等待中重新检测。 |
| 选择“恢复原宠物”或退出助手 | 停止监测和接入；已连接时恢复原图。 |

从普通图标启动时缺少接入通道这一限制仍然存在。v0.5.3 修复的是持续检测、进程替换和重连流程，不能保证任意启动方式都无需重开。

## 实际操作

1. 以后优先使用大肥鱼助手入口，一次打开 Codex 和宠物。
2. 若当前已经手动打开 Codex，先继续完成工作。需要接入时，在助手中点“安排接入”。
3. 从系统托盘完整退出 Codex，保持助手运行。
4. 助手自动打开并接入后，收起到托盘即可。

只关闭 Codex 主窗口可能仍在后台运行；需要接续时应从系统托盘完整退出。助手保留这台电脑原来的账号与数据。

## 源码使用

`node launch.mjs start --wait-for-exit --open-pet --watch-codex` 启用持续检测。没有 `--watch-codex` 时沿用单次连接会话；显式 `--port` 限定单个调试端口。Windows 便携助手默认使用监测模式。

检测仅在助手启用期间运行，没有新增开机启动，也没有修改官方 Codex 图标或安装文件。仍为非官方适配，其他电脑及其他客户端版本需要验证。
