大肥鱼 · Codex 宠物助手
第一次使用，请先读这里

适用：Windows x64，已安装并登录官方 Codex。
便携包已包含模型和 Node.js，首次准备需要联网下载动画运行库。
本工具为非官方适配器，角色显示在官方 Codex 的宠物窗口中。

一、第一次在这台电脑使用

1. 打开官方 Codex，登录你自己的账号。
   选择任意内置宠物或已有自定义宠物，并显示宠物窗口。

2. 从项目 Releases 下载 Windows x64 便携 zip，完整解压到固定文件夹，
   例如 D:\Codex-Dafeiyu。
   CodexDafeiyu.exe、assets 和 runtime 应位于同一解压目录中。
   保持所有文件在一起，从解压后的文件夹运行。

3. 双击 CodexDafeiyu.exe。
   首次会显示动画组件说明。点击链接阅读 Live2D Core 许可，勾选同意并确认。
   助手从 Live2D 官方下载约 203 KB 的运行库并校验文件。
   准备完成后，以后无需重复下载；每台新电脑需单独完成首次准备。

4. 如果面板显示“等待 Codex 正常退出”：
   先完成并保存当前工作，再从 Windows 系统托盘完整退出 Codex。
   只关闭 Codex 窗口可能仍在后台运行。
   保持大肥鱼助手运行，它会等候 Codex 正常退出，随后使用这台电脑原来的
   账号和数据自动重新打开并连接。

5. 面板显示“已连接 Codex”、宠物窗口出现大肥鱼，即完成。
   点击“收起到托盘”隐藏面板，宠物继续运行。

二、以后怎么启动和关闭

- 从 CodexDafeiyu.exe 或它的快捷方式启动。
  可右键该 exe，创建桌面快捷方式。助手会启动 Codex 并接入宠物。
- 已在后台运行时，再次双击 exe 或双击系统托盘图标，可打开同一个面板。
- 点面板右上角 ×，先选择“收起到托盘 / 退出助手 / 取消”。
  默认收起，按 Esc 取消关闭。
- 选择“恢复原宠物”或“退出助手”，会停止 Live2D 并恢复原图，Codex 继续运行。
- 面板和托盘菜单可切换 30/60 FPS、恢复自动跟随、查看日志。
- 面板主题可选跟随系统、浅色、深色。
- 默认开启拖窗兼容模式：移动或缩放 Codex 普通窗口时暂时收起宠物，结束后自动恢复。
  可勾选同一卡片的“提前避让”（默认关闭），旁边可选择触发方式。
  “按下时（推荐）”：鼠标在顶部／边框按下才收起，松手后恢复，单纯经过不收起。
  “移入时”：移入顶部／边框就收起，移开约 0.2 秒后恢复；松手仍停在顶部时需移开。
  可随时取消或换方式。移入模式本机已验证拖动起步无闪烁；按下模式准备时间较短，
  极快拖动仍可能轻闪。其他电脑的实际效果需要验证，底层问题尚未根治。
  原本隐藏的宠物保持隐藏；也可取消勾选，继续采用屏幕最左侧的摆放绕法。
- 点“表情 / 装扮…”可选择 20 项表情、10 类装扮与工具，并播放 3 项桌面效果。
  右侧可切换动态 / 静态预览；动态跟随 30/60 FPS 设置。选择后先预览，点“应用”才保存到宠物。
  表情、装扮分成两个页签；20 种脸部表情可直接点选预览，预览背景可单独选浅、深或棋盘。
  自动轮换默认覆盖全部 20 种，一轮内不重复；日常范围为 12 种，一轮约 3–4 分钟。
  普通任务运行时也会换脸，状态切换优先短暂表达，持续审查不再锁住轮换；手动固定表情会暂停轮换。
  同类装扮一次选一种，不同类别可组合；设置在本机保存，下次启动继续使用。
  “恢复默认”会清除自选装扮，恢复自动表情与模型默认外观。
  静态手势在动作结束后显示；手机配色在拿出手机时可见。
  画笔、橡皮为工具姿态；撤回和点菜为按压展示，不包含实际画板或点餐功能。
  如果系统没有 WebView2 运行库，助手会提供基础设置界面，仍可应用外观和播放效果。

三、没有出现大肥鱼时

- 等待 Codex 正常退出：按第一部分第 4 步完整退出 Codex，保持助手运行。
- 正在等待宠物窗口：在 Codex 中确认已选择宠物并显示宠物窗口。
- 等待已固定的宠物：点击助手面板里的“恢复自动跟随”。
- 暂未连接 / 暂未接入：点击“查看日志”，检查首次运行库准备是否完成。
  反馈问题时附助手版本、Codex 版本和错误文字；先在本机检查日志，再决定分享内容。
- 缺少运行环境或资源：重新完整解压便携 zip，从解压后的目录运行 exe。
- 刚启动时短暂出现原宠物：属于正常加载过程，连接成功后才隐藏原图。
- 拖动 Codex 主窗口时来回跳动：先将仍在显示的宠物拖到屏幕最左侧，再试主窗口。
  本机已验证左侧顺畅，也可移动主窗口前暂时隐藏整个宠物窗口。
  “恢复原宠物”仍保留原生宠物窗口，不等于隐藏。放回右侧可能复现，底层问题尚未修复。
- 恢复原宠物：助手会验证原图；加载失败时只刷新宠物小窗口一次，聊天窗口保持运行。
  如果提示“大肥鱼已停用，原宠物未显示”，可再次恢复、启用大肥鱼或查看日志。
  网络或云端图片持续不可用时，助手无法保证原图显示；不会反复刷新或误报成功。

四、分享、升级与卸载

- 分享完整便携 zip，接收者使用自己的 Codex 账号和宠物。
  聊天记录、登录数据和本机配置保留在各自电脑上。
- 升级前，在旧助手中明确选择退出；把新版完整解压到新文件夹，再启动新版。
  已有配置和已准备的运行库保存在本机，可继续使用。
- 卸载时退出助手，再删除它的解压目录。
  助手配置和日志位于 %LOCALAPPDATA%\CodexDafeiyuLive2D，可按需另行删除。
